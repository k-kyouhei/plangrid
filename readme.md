# PlanGrid

旅行や連休の予定を、**「スケジュール表 × 待機エリア（候補ストック）」**で直感的に組み立てられる、単一HTMLファイル完結のスケジュール整理ボードです。

サーバーや外部ライブラリを一切使わず、`index.html` 1枚だけで動作するため、GitHub Pages で運用コスト 0 円・メンテナンスフリーで公開できます。

- **Demo**: https://k-kyouhei.github.io/plangrid/

---

## コンセプト

「行きたいお店や観光候補をストックしておき、日程のコマに当てはめながら入れ替え・並べ替えをする」ことに特化したミニマルな計画ツールです。

- **開いてすぐ使える**: ログインやアカウント登録は不要。すべてのデータはブラウザ内（`localStorage`）に自動一時保存されます。
- **AIと相性の良い出力**: 組み立てた予定と未配置の候補をワンクリックで Markdown コピーし、そのまま生成AIに渡してルート最適化や改善案を相談できます。
- **スクショ共有に最適化**: 編集UIをワンクリックで隠せる「スクショ表示」により、完成した行程表をそのまま家族や同行者へ画像共有できます。

## 主な機能

### スケジュール表 & 待機エリア
- **自由な軸のカスタマイズ**: 横軸（日付・列）と縦軸（時間帯・行）の見出し編集、追加・削除に対応。列や行を削除しても、配置済みのカードは消えずに待機エリアへ自動で退避されます。
- **待機エリア（候補ストック）**: 行きたいお店やスポットを先に登録しておき、決まった枠へドラッグして当てはめられます。パネルの折りたたみにも対応。

### カード管理 & 色ラベル
- **6色のソフトパステル分類**: カードを6色で色分けでき、色ごとのラベル名（例：`自分` / `妻` / `ごはん` / `予約済` / `その他` / `メモ`）を自由にカスタマイズ可能。
- **スッキリ表示 & 詳細メモ**: 表上では2行＋省略記号（`…`）でコンパクトに収まり、カードをタップすると全文の閲覧・編集・複製・削除ができます。

### PC・タブレット・スマホ両対応
- **誤操作を防ぐドラッグ操作**: カード左端のつまみ（`⋮⋮`）を掴んだときだけドラッグ移動（Pointer Events）になるため、スマホでも画面スクロールと干渉しません。
- **片手移動UI**: カード編集モーダル内の「配置先プルダウン」と「↑ 上へ / ↓ 下へ」ボタンから、ドラッグなしでも確実に枠移動・順番入れ替えができます。

### 表示カスタマイズ & スクショ表示
- **全体スタイル設定**: フォント（ゴシック / 明朝 / 丸ゴシック・等幅系）、文字サイズ（小 12px / 中 14px / 大 16px）、背景色（5種類）をボード全体で一括変更できます。
- **スクショ表示モード**: ツールバー・待機エリア・追加/削除ボタンを隠し、タイトル・凡例・スケジュール表だけを表示します。

### エクスポート・インポート & 履歴管理
- **Markdown コピー（AI相談用）**: 日付・時間帯ごとの予定（色ラベル＋詳細メモ全文＋空き枠）と、待機中の候補を整理した Markdown をクリップボードへコピーします。
- **JSON コピー & 読込（バックアップ用）**: ボード全データを JSON 形式でコピー・貼り付け復元でき、別端末への移行やテンプレート再利用に活用できます。
- **Undo / Redo & 自動保存**: 最大 50 ステップの履歴管理（`Ctrl+Z` / `Ctrl+Y`）と `localStorage` 自動保存に対応。リセットは「カードを全消去」「初期テンプレートに戻す」の2段階から選べます。

## AI相談での活用例

ヘッダーの **「エクスポート」→「Markdownでコピー (AI相談用)」** を押すと、以下のような形式でコピーされます。

```markdown
# 3連休プラン

## 11/21(土)
- **午前**: [妻] 県立美術館の企画展 10:00開館・オンライン前売券あり
- **昼ごはん**: (空き)
- **午後**: (空き)
- **夕ご飯**: (空き)
- **夜**: (空き)

## 11/22(日)
- **午前**: (空き)
- **昼ごはん**: (空き)
- **午後**: (空き)
- **夕ご飯**: [予約済] イタリアン △△（18:30予約済・駐車場3台）
- **夜**: (空き)

## 待機中の候補（未配置）
- [ごはん] 駅前うどん 〇〇 11:30前に着くと並ばず入れる・日曜定休
- [自分] 海沿いドライブ＆展望台カフェ
```

そのまま生成AIのチャットに貼り付けて、以下のように相談できます。

> 「このスケジュールと待機中の候補を見て、移動効率や定休日・お互いの希望バランスを考慮したおすすめの当てはめ案を提案して」

## キーボードショートカット

| ショートカット | 動作 |
| :--- | :--- |
| `Ctrl + Z` / `Cmd + Z` | 元に戻す（Undo） |
| `Ctrl + Y` / `Cmd + Shift + Z` | やり直す（Redo） |
| `Ctrl + Enter` / `Cmd + Enter` | カード編集モーダルの保存 |
| `Esc` | モーダルを閉じる / スクショ表示を解除 |

## 使い方・デプロイ方法

### ローカルで動かす
リポジトリをクローンまたはダウンロードし、`index.html` をブラウザで直接開くだけで動作します（ビルド手順・ローカルサーバー不要）。

### GitHub Pages で公開する
1. このリポジトリ（`k-kyouhei/plangrid`）に `index.html` を配置して `main` ブランチへプッシュします。
2. GitHub のリポジトリページで **Settings** → **Pages** を開きます。
3. **Build and deployment** の Source で **Deploy from a branch** を選び、Branch に `main` / `/ (root)` を指定して **Save** をクリックします。
4. 数十秒〜数分後、`https://k-kyouhei.github.io/plangrid/` で公開されます。

## 技術スタック・設計方針

- **構成**: Vanilla HTML / CSS / JavaScript（単一ファイル・ビルドツール不使用）
- **外部依存**: なし（外部CDN・外部フォント不使用、オフライン環境でも動作）
- **データ保存**: ブラウザの `localStorage`（サーバーへのデータ送信は一切行いません）
